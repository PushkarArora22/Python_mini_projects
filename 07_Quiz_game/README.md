# 🧠 Python Quiz Game

A simple terminal-based quiz game built with Python. The game asks the player five multiple-choice questions, checks their answers, keeps track of their score, and displays the final score and percentage.

## 🎮 Features

* 5 multiple-choice questions
* Automatic answer checking
* Score tracking
* Percentage calculation
* Accepts lowercase or uppercase answers
* Simple and beginner-friendly terminal interface

* Python 3

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python quiz_game.py
```

4. Answer each question by entering `A`, `B`, `C`, or `D`.
