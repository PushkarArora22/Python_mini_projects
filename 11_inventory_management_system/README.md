# Inventory Management System

A Python command-line inventory management system for tracking products, stock levels, prices, and inventory value.

## Overview

The Inventory Management System allows users to manage a simple product inventory through an interactive command-line interface.

Users can add products, view inventory, search for products, update stock levels, remove products, calculate total inventory value, and identify low-stock products.

## Features

- Add new products
- View all products in inventory
- Search for products by name
- Update product stock
- Remove products
- Calculate total inventory value
- Identify low-stock products
- Validate user input
- Interactive command-line menu
