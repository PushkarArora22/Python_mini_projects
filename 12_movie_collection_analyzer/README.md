# 🎬 Movie Collection Analyzer

A Python command-line application for managing and analyzing a personal movie collection.

## 📌 Overview

Movie Collection Analyzer is an interactive Python program that allows users to manage their personal movie collection through a simple command-line interface.

Users can add, view, search, remove, sort, and analyze movies while practicing fundamental Python list operations.

## ✨ Features

- ➕ Add movies to the collection
- 📋 View all movies
- 🔍 Search for movies
- 🗑️ Remove movies
- 🔤 Sort movies alphabetically
- 🔄 View movies in reverse order without modifying the original collection
- 📊 View collection statistics
- 🛡️ Prevent duplicate movie entries
- ⚠️ Basic input validation

## 🖥️ Example Usage

```text
=== Movie Collection Analyzer ===
1. Add Movie
2. View Movies
3. Search Movie
4. Remove Movie
5. Sort Movies Alphabetically
6. View Movies in Reverse
7. Show Collection Statistics
8. Exit

Choose an option (1-8): 1
Enter movie name: Interstellar

"Interstellar" added successfully.
```
