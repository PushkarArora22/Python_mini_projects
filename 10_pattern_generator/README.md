# Number Pattern Generator

A Python command-line program that generates different number and symbol patterns based on user-selected options and size.

## Features

- Star pyramid
- Reverse star pyramid
- Number triangle
- Multiplication grid
- User-selected pattern and size
- Input validation

## Concepts Used

- Python functions
- `for` loops
- Nested loops
- `range()`
- Conditional statements
- `try/except`
- User input
- Basic arithmetic
- String formatting

## How to Run

Make sure Python is installed.

Run:

```bash
python pattern_generator.py
