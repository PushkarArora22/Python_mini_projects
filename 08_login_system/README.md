# 🔐 Python Login System

A simple command-line login system built with Python. The project allows users to register an account, confirm their password, and log in using their saved credentials.

## 🚀 Features

* User registration
* Password confirmation
* Username and password verification
* Interactive command-line menu
* `match/case` menu selection
* Invalid choice handling
* Program exit using `sys.exit()`

## 🧠 Concepts Used

* Variables
* Functions
* User input
* `if/else`
* `match/case`
* `while` loops
* `global` variables
* String comparison
* `sys.exit()`

## ▶️ How to Run

Make sure Python is installed, then run:

```bash
python login system.py
```

Follow the instructions displayed in the terminal.

## ⚠️ Note

This is a beginner Python learning project. User credentials are stored only while the program is running and are not securely stored or encrypted.
