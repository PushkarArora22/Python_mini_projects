## 📂 Projects

### 1. 🧮 Mini Calculator
A command-line calculator supporting:
- Addition
- Subtraction
- Multiplication
- Division
- Invalid operator handling
- Division by zero handling

📁 Folder: `01_Mini_Calculator`

---

### 2. 📝 Text Analyzer
A command-line text analyzer that displays:
- Character count
- Word count
- Uppercase conversion
- Lowercase conversion
- Reversed text
- Vowel count
- Space count

📁 Folder: `02_Text_Analyzer`
